Which neighbour counts as "previous" depends on the layout: the docs section reads its pages in reverse (theme behaviour, kept as-is), so there the left item is Hugo's NextInSection. Working out left/right first keeps the label and the position in agreement for both kinds of page. */}} {{- $prev := .PrevInSection -}} {{- $next := .NextInSection -}} {{- if eq .Type "docs" }}{{ $prev = .NextInSection }}{{ $next = .PrevInSection }}{{ end -}} {{- if or $prev $next }}

{{- end }} {{- with $next }}

{{- end }}
{{- end }}
